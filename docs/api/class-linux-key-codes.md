Key codes for Linux.

List of all key code accessors:

- <kbd>0</kbd> – <kbd>9</kbd>
- <kbd>A</kbd> – <kbd>Z</kbd>
- <kbd>KeyA</kbd> – <kbd>KeyZ</kbd>
- <kbd>F1</kbd> – <kbd>F12</kbd>
- <kbd>Escape</kbd>
- <kbd>Tab</kbd>
- <kbd>Enter</kbd>
- <kbd>Backspace</kbd>
- <kbd>Delete</kbd>
- <kbd>ForwardDelete</kbd>
- <kbd>Insert</kbd>
- <kbd>Home</kbd>
- <kbd>End</kbd>
- <kbd>PageUp</kbd>
- <kbd>PageDown</kbd>
- <kbd>ArrowLeft</kbd>
- <kbd>ArrowUp</kbd>
- <kbd>ArrowRight</kbd>
- <kbd>ArrowDown</kbd>
- <kbd>Left</kbd>
- <kbd>Up</kbd>
- <kbd>Right</kbd>
- <kbd>Down</kbd>
- <kbd>Space</kbd>
- <kbd>Spacebar</kbd>
- <kbd>Comma</kbd>
- <kbd>Period</kbd>
- <kbd>FullStop</kbd>
- <kbd>Minus</kbd>
- <kbd>Dash</kbd>
- <kbd>Equals</kbd>
- <kbd>Backslash</kbd>
- <kbd>LeftSquareBracket</kbd>
- <kbd>RightSquareBracket</kbd>
- <kbd>SingleQuote</kbd>
- <kbd>Backtick</kbd>
- <kbd>,</kbd>
- <kbd>.</kbd>
- <kbd>-</kbd>
- <kbd>=</kbd>
- <kbd>\\</kbd>
- <kbd>[</kbd>
- <kbd>]</kbd>
- <kbd>'</kbd>
- <kbd>`</kbd>

Lowercase letters <kbd>a</kbd> – <kbd>z</kbd> are also supported.

The letter accessors map to X11 keysyms for the corresponding lowercase letters. Uppercase letters and `KeyA` – `KeyZ` use the same keysyms as their lowercase equivalents; Shift determines whether the resulting character is uppercase.

These values represent X11 keysyms used for Linux keyboard input.
