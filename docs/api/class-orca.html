Orca

Implements: IScreenReader

An Orca instance can be used to launch and control Orca on Linux. The API is currently available through the preview unstable_orca export.

Here's a typical example using an Orca instance:

import { unstable_orca } from "@guidepup/guidepup";

(async () => {
  // Start Orca.
  await unstable_orca.start();

  // Move to the next item.
  await unstable_orca.next();

  // Stop Orca.
  await unstable_orca.stop();
})();

unstable_orca.keyboardCommands​

Getter for the Orca keyboard commands supported by Guidepup.

Use a command with perform to invoke it:

import { unstable_orca } from "@guidepup/guidepup";

(async () => {
  // Start Orca.
  await unstable_orca.start();

  // Move to the next item.
  await unstable_orca.perform(unstable_orca.keyboardCommands.MoveToNextSibling);

  // Stop Orca.
  await unstable_orca.stop();
})();

Each command includes its command name, description, keyboard representation, and Orca service.

See OrcaKeyCodeCommands for the available commands.

Returns: OrcaKeyCodeCommands

unstable_orca.act([options])​

Perform the default action for the item in the Orca cursor.

Equivalent of executing Orca+Control+Enter.

import { unstable_orca } from "@guidepup/guidepup";

(async () => {
  await unstable_orca.start();
  await unstable_orca.next();
  await unstable_orca.act();
  await unstable_orca.stop();
})();

Parameters:

  • Optional: options Pick<CommandOptions, "capture"> Capture options.

Returns: Promise<void>

unstable_orca.capture(action[, options])​

Capture Orca output produced while an action runs. The action can be performed using an external automation tool such as Playwright. The returned capture contains the action's result and the Orca output associated with the action.

import { test } from "@playwright/test";
import { unstable_orca } from "@guidepup/guidepup";

test("capture Orca output while clicking a button", async ({ page }) => {
  await unstable_orca.start();

  const capture = await unstable_orca.capture(() =>
    page
      .getByRole("button", {
        name: "Submit",
      })
      .click(),
  );
  console.log(capture);

  await unstable_orca.stop();
});

Parameters:

  • action () => Promise<T> | T The action to perform while capturing Orca output.
  • Optional: options Pick<CommandOptions, "capture"> Capture options.

Returns: Promise<Capture<T>> The action's result and captured Orca output.

unstable_orca.click([options])​

Click the mouse.

import { unstable_orca } from "@guidepup/guidepup";

(async () => {
  await unstable_orca.start();
  await unstable_orca.click({ button: "left", clickCount: 1 });
  await unstable_orca.click({ button: "right", clickCount: 2 });
  await unstable_orca.stop();
})();

Parameters:

  • Optional: options ClickOptions Click options.

Returns: Promise<void>

unstable_orca.default()​

Detect whether Orca is the default screen reader for the current OS:

  • false for Windows
  • false for macOS
  • true for Linux

This detects the operating system; it does not check whether Orca is installed.

import { unstable_orca } from "@guidepup/guidepup";

console.log(unstable_orca.default());

Returns: boolean

unstable_orca.detect()​

Detect whether Orca is supported on the current operating system:

  • false for Windows
  • false for macOS
  • true for Linux

This detects the operating system; it does not check whether Orca is installed. start() will fail if Orca is not installed.

import { unstable_orca } from "@guidepup/guidepup";

console.log(unstable_orca.detect());

Returns: boolean

unstable_orca.getSetting(key)​

Returns the value of a setting for this Orca instance.

import { unstable_orca } from "@guidepup/guidepup";

(async () => {
  await unstable_orca.start();
  console.log(
    unstable_orca.getSetting("/org/gnome/orca/default/speech/enable"),
  );
  await unstable_orca.stop();
})();

Parameters:

  • key string The setting name.

Returns: unknown The setting value.

unstable_orca.itemTextLog()​

Get the log of all visited item text for this Orca instance.

For Orca this is the same as spokenPhraseLog.

import { unstable_orca } from "@guidepup/guidepup";

(async () => {
  await unstable_orca.start();
  for (let i = 0; i < 10; i++) {
    await unstable_orca.next();
  }
  console.log(await unstable_orca.itemTextLog());
  await unstable_orca.stop();
})();

Returns: Promise<Array<string>> The item text log.

unstable_orca.perform(command[, options])​

Perform an Orca keyboard command.

The command can be any OrcaKeyCodeCommand exposed through OrcaKeyCodeCommands, available as unstable_orca.keyboardCommands or the orcaKeyCodeCommands export.

import { unstable_orca } from "@guidepup/guidepup";

(async () => {
  await unstable_orca.start();
  await unstable_orca.perform(unstable_orca.keyboardCommands.MoveToNextSibling);
  await unstable_orca.stop();
})();

Parameters:

  • command OrcaKeyCodeCommand Orca keyboard command.
  • Optional: options Pick<CommandOptions, "capture"> Capture options.

Returns: Promise<void>

unstable_orca.start([options])​

Turn Orca on. Orca must be installed on Linux.

By default, capture is set to "initial": it captures the first page of output, but not subsequent content. Set capture to true for full capture or false to disable capture.

import { unstable_orca } from "@guidepup/guidepup";

(async () => {
  await unstable_orca.start();
  // ... perform some commands.
  await unstable_orca.stop();
})();

Parameters:

  • Optional: options Pick<StartOptions, "capture" | "settings"> Capture and screen reader settings options.

Returns: Promise<void>
